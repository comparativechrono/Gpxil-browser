      How to fly the pixelverse

      Every pixel is one base of the human reference genome (GRCh38): A C G T, pale where the base is in a repeat, grey for unknown (N). Zoomed out, a pixel is the average colour of the bases it covers. Rows wrap like lines of text.

      What you are looking at

      This is a browser for gpxil, a file format that stores genomes as images, after Guenter Albrecht-Buehler's genome pixel images (PLoS ONE, 2009). The bases come straight from the GRCh38 gpxil files: the browser reads just the strips of pixels it needs with HTTP range requests.

      Only when you ask for them, a few things come live from other databases: variants, regulatory elements, rsID lookups and names the gene index doesn't know from the Ensembl REST API, and gene summaries from NCBI Gene via MyGene.info.

      Take the pixels home

      The genome as gpxil

      The whole GRCh38 reference in one gpxil file, GRCh38.gpxil.tif (about 850 MB; SHA-256), or a chromosome at a time: these are the files this browser reads.

        Read them with gpxiltools (pip install git+https://github.com/comparativechrono/Gpxil-tools, then gpxil info chr17.gpxil.tif), or open them in any TIFF viewer.

        Genes, transcripts and proteins as pxil

        Open a gene and use Download as pixels in its panel: .gene.pxil.png, .transcript.pxil.png and .protein.pxil.png files, one at a time or zipped, each named with its Ensembl ID. pxil is a simple format for single sequences: PNG images that open in any image viewer and whose pixel values are the sequence. It is good for quick analysis and sharing, while gpxil is for keeping genomes.
